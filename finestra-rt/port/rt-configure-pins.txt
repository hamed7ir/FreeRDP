# ARM32 / Windows RT 8.1 -- configure, build and verify sequence for the SDL3 client
# (sdl-freerdp.exe), the engine Finestra ships. The Windows client (wfreerdp) builds from
# the same configure line with WITH_CLIENT_SDL=OFF and target wfreerdp.
#
# Paths below are written as <PLACEHOLDERS>. Substitute your own; nothing here assumes
# a particular machine layout. Run from PowerShell, in this order.
#
#   <REPO>      the root of this checkout
#   <BUILD>     any empty build directory OUTSIDE the checkout
#   <EXTLIBS>   directory holding the three ARM32 libraries built in STEP 0a
#               (libcrypto.lib, libssl.lib, z.lib) -- see ../NOTICE.txt section 2
#   <SDL3>, <FT>, <TTF>   install prefixes of the three libraries built in STEP 0b
#
# COMPILER: the SDL3 client is C++ and was built with rt2.1 (LLVM 23.1.1-rt2.1, the
# hamed7ir/llvm-rt1 series) against MSVC 14.44's lib\arm; set LLVM_ROOT and
# MSVC_ARM32_LIB_DIR accordingly BEFORE every step, including STEP 0. Stock LLVM 18
# miscompiles some ARM32 C++ and rejects __try (SDL uses it). Every library below was
# built by the same compiler.

# --- STEP 0a: build OpenSSL and zlib from the official source releases ---
#   powershell -File <REPO>\finestra-rt\port\build-openssl-arm32.ps1 -Source <openssl-3.5.9> -Build <dir> -Out <ossl>
#   powershell -File <REPO>\finestra-rt\port\build-zlib-arm32.ps1    -Source <zlib-1.3.2>    -Build <dir> -Out <zlib>
#   then put <ossl>\lib\libcrypto.lib, <ossl>\lib\libssl.lib and <zlib>\z.lib in <EXTLIBS>.
#   (The OpenSSL script also needs a native Windows Perl and MSVC's host nmake; see its header.)

# --- STEP 0b: build SDL 3.2.14, FreeType 2.15.0 and SDL3_ttf 3.2.2 (static, /MT, ARMNT) ---
#   Any CMake toolchain file that targets ARM32 Windows with the compiler above works; the
#   shipped libraries used hamed7ir/scrcpy-rt's cross/rt2-arm32-toolchain.cmake (armv7 triple,
#   SDK 10.0.19041.0, /MACHINE:ARM, SDL_ASSEMBLY and every SIMD option OFF) with RT2 pointing at
#   rt2.1's bin and llvm-rc as the resource compiler. All three: -G Ninja -DCMAKE_BUILD_TYPE=Release
#   -DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded, and:
#   SDL3     -DSDL_SHARED=OFF -DSDL_STATIC=ON -DSDL_TESTS=OFF -DSDL_EXAMPLES=OFF -DSDL_AUDIO=ON
#            -DSDL_OPENGL=OFF -DSDL_OPENGLES=OFF -DSDL_RENDER_D3D=ON -DSDL_RENDER_D3D11=ON
#            -DSDL_RENDER_D3D12=OFF -DSDL_VULKAN=OFF -DSDL_GPU=OFF -DSDL_CAMERA=OFF -DSDL_JOYSTICK=OFF
#            -DSDL_HAPTIC=OFF -DSDL_HIDAPI=OFF -DSDL_DIALOG=OFF -DSDL_POWER=OFF -DSDL_SENSOR=OFF
#            -DCMAKE_INSTALL_PREFIX=<SDL3>
#   FreeType -DBUILD_SHARED_LIBS=OFF -DFT_DISABLE_ZLIB=ON -DFT_DISABLE_BZIP2=ON -DFT_DISABLE_PNG=ON
#            -DFT_DISABLE_HARFBUZZ=ON -DFT_DISABLE_BROTLI=ON -DCMAKE_INSTALL_PREFIX=<FT>
#   SDL3_ttf -DBUILD_SHARED_LIBS=OFF -DSDLTTF_VENDORED=OFF -DSDLTTF_HARFBUZZ=OFF -DSDLTTF_PLUTOSVG=OFF
#            -DSDLTTF_SAMPLES=OFF -DSDLTTF_INSTALL=ON "-DCMAKE_PREFIX_PATH=<SDL3>;<FT>"
#            "-DCMAKE_FIND_ROOT_PATH=<SDL3>;<FT>" -DCMAKE_INSTALL_PREFIX=<TTF>
#   (cmake --build <dir> --target install for each, in that order.)

# --- STEP 1: environment (MANDATORY, same shell as both cmake and ninja) ---
#   . <REPO>\finestra-rt\port\armenv.ps1
#
# armenv.ps1 sets INCLUDE (MSVC 14.4x headers + Windows SDK 10.0.19041.0), LIB
# (MSVC lib\arm -- 14.44 for the SDL3 client, the 14.16 default for the Windows client --
# plus SDK ucrt\arm and um\arm) and prepends LLVM + Ninja to PATH. It warns for every
# path it cannot find; fix those before continuing rather than reading the clang errors
# that follow. Override any path with the matching environment variable BEFORE dot-sourcing.

# --- STEP 2: configure ---

cmake -S <REPO> `
      -B <BUILD> `
      -G Ninja `
      -DCMAKE_TOOLCHAIN_FILE=<REPO>/finestra-rt/port/thumbv7-rt.cmake `
      "-DCMAKE_PREFIX_PATH=<SDL3>;<TTF>;<FT>" `
      -DCMAKE_WINDOWS_VERSION=WIN81 `
      -DCMAKE_BUILD_TYPE=Release `
      -DBUILD_SHARED_LIBS=OFF `
      -DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded `
      -DOPENSSL_USE_STATIC_LIBS=ON `
      -DOPENSSL_ROOT_DIR=<EXTLIBS> `
      -DOPENSSL_INCLUDE_DIR=<REPO>/finestra-rt/deps-headers/openssl-3.5.9/include `
      -DLIB_EAY_RELEASE=<EXTLIBS>/libcrypto.lib `
      -DSSL_EAY_RELEASE=<EXTLIBS>/libssl.lib `
      -DZLIB_INCLUDE_DIR=<REPO>/finestra-rt/deps-headers/zlib-1.3.2 `
      -DZLIB_LIBRARY=<EXTLIBS>/z.lib `
      -DZLIB_LIBRARY_RELEASE=<EXTLIBS>/z.lib `
      -DWITH_WINMM=ON `
      -DWITH_NATIVE_SSPI=OFF `
      -DWITH_INTERNAL_RC4=ON `
      -DWITH_INTERNAL_MD4=ON `
      -DWITH_INTERNAL_MD5=OFF `
      -DWITH_KRB5=OFF `
      -DWITH_SERVER=OFF `
      -DWITH_SAMPLE=OFF `
      -DWITH_CLIENT_SDL=ON `
      -DWITH_CLIENT_SDL3=ON `
      -DWITH_CLIENT_SDL2=OFF `
      -DWITH_SDL_LINK_SHARED=OFF `
      -DWITH_FFMPEG=OFF `
      -DWITH_SWSCALE=OFF `
      -DWITH_CAIRO=OFF `
      -DWITH_SIMD=OFF `
      -DWITH_JPEG=OFF `
      -DWITH_JSON_DISABLED=ON `
      -DWITH_WINPR_TOOLS=OFF `
      -DWITH_WINDOWS_CERT_STORE=OFF `
      -DWITH_PROGRESS_BAR=OFF `
      -DWITH_MANPAGES=OFF `
      -DWITH_MEDIA_FOUNDATION=OFF `
      -DWITH_OPENH264=OFF `
      -DCHANNEL_URBDRC=OFF `
      -DUSE_UNWIND=OFF `
      -DBUILD_TESTING=OFF `
      -DWITH_VERBOSE_WINPR_ASSERT=OFF

# WITH_VERBOSE_WINPR_ASSERT=OFF matches the shipped engines; FreeRDP's default is ON.
# WITH_NATIVE_SSPI=OFF is required: RT 8.1 has no usable native SSPI, so WinPR's
# internal NTLM is used -- and NTLMv2 then needs RC4/MD4, which OpenSSL 3's default
# provider no longer offers, hence WITH_INTERNAL_RC4/MD4=ON.
# WITH_SIMD=OFF avoids NEON alignment faults on Tegra 3 class hardware.
# CMAKE_WINDOWS_VERSION=WIN81 requires this fork's WIN81 commit; upstream has no such case.

# --- STEP 3: build ---
#   cmake --build <BUILD> --target sdl3-freerdp
#   (or: ninja -C <BUILD> sdl3-freerdp -- same shell as STEP 1; the Windows client is target wfreerdp)

# --- STEP 4: MANDATORY import gate before trusting the binary ---
#   llvm-readobj --file-headers --coff-imports <BUILD>\client\SDL\SDL3\sdl-freerdp.exe
#   PASS requires all three:  machine = IMAGE_FILE_MACHINE_ARMNT (0x1C4)
#                             ZERO api-ms-win-* imports
#                             NO secur32.dll import
#   RT 8.1 lacks the API-set umbrella DLLs and native SSPI; a violation fails to LOAD,
#   not to degrade -- the binary simply will not start on the target.
#   Also: BCryptGenRandom must be imported from bcrypt.dll (WinPR imports bcrypt.dll, and
#   OpenSSL uses BCryptGenRandom; RT 8.1 has it - ../NOTICE.txt section 3). The toolchain
#   lists bcrypt.lib first so it cannot resolve through the forwarder in ncrypt.dll instead.

# --- Not passed as -D pins; injected by finestra-rt/port/thumbv7-rt.cmake ---
#   clang-cl-arm-shim.h  force-included via /FI, resolved beside the toolchain file
#   /EHsc and /UWINPR_DEFINE_ATTR_NODISCARD for C++ sources (the SDL3 client)
#   the MSVC default Windows import-lib set, with bcrypt.lib first
#     (bcrypt gdi32 winspool shell32 ole32 oleaut32 uuid comdlg32 advapi32)
#
# No CRT shim archive is required. An earlier dependency survey rated one "likely
# needed" from symbol content alone; a real RT link resolves with zero undefined
# symbols without it.
