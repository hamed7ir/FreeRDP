NOTICE -- finestra-rt/ (ARM32 / Windows RT 8.1 cross-build material)
===================================================================

This directory is NOT part of upstream FreeRDP. It is added by the Finestra fork to
make the ARM32 (thumbv7 / ARMNT) engine build reproducible from documented sources.
Upstream FreeRDP is licensed Apache-2.0; everything here is compatible with that.

--------------------------------------------------------------------------------
1. WHAT IS HERE
--------------------------------------------------------------------------------
  port/thumbv7-rt.cmake          CMake toolchain file for thumbv7-unknown-windows-msvc
  port/armenv.ps1                companion environment script (must be dot-sourced)
  port/clang-cl-arm-shim.h       compatibility shim, (c) 2026 Hamed Ghorbani, Apache-2.0
  port/build-openssl-arm32.ps1   builds the ARM32 OpenSSL libraries from source -- see 2
  port/build-zlib-arm32.ps1      builds the ARM32 zlib library from source -- see 2
  port/rt-configure-pins.txt     the exact configure/build/verify command sequence
  deps-headers/openssl-3.5.9/    GENERATED OpenSSL headers matching those libraries -- see 4
  deps-headers/zlib-1.3.2/       zlib headers matching z.lib

No prebuilt binary of any kind is in this directory.

--------------------------------------------------------------------------------
2. WHAT IS *NOT* HERE -- THREE LIBRARIES YOU BUILD
--------------------------------------------------------------------------------
The ARM32 build links three static libraries that are NOT included in this repository:

    libcrypto.lib     OpenSSL 3.5.9, ARM32 (ARMNT), static /MT
    libssl.lib        OpenSSL 3.5.9, ARM32 (ARMNT), static /MT
    z.lib             zlib 1.3.2,    ARM32 (ARMNT), static /MT

Build them from the official source releases with the two scripts in port/:

    port/build-openssl-arm32.ps1 -Source <openssl-3.5.9> -Build <dir> -Out <dir>
    port/build-zlib-arm32.ps1    -Source <zlib-1.3.2>    -Build <dir> -Out <dir>

and point the engine build at them with -DLIB_EAY_RELEASE, -DSSL_EAY_RELEASE and
-DZLIB_LIBRARY (see port/rt-configure-pins.txt for the full command).

The OpenSSL script runs OpenSSL's own VC-WIN32-ARM target with clang-cl and llvm-lib
substituted for MSVC's ARM tools, with the engine toolchain's compile flags and these
options: no-asm enable-static-engine enable-capieng no-tests no-docs no-shared
no-module no-apps no-uplink, and _WIN32_WINNT=0x0603. Each script states its reasons
in its header.

VERIFIED 2026-10-21: both scripts were run from scratch and produced the libraries the
engine links. Built twice in different directories, the zlib script's output was
byte-identical. The OpenSSL script compiles with /Brepro, but its output has NOT been
checked for byte-identity, and OpenSSL's own /Zi debug information records the build
paths, so expect differences between machines.

`no-asm` is not optional: there is no ARM32 assembly path through clang-cl, and the
generated headers in deps-headers/openssl-3.5.9 are configured to match (see 4).

The OpenSSL libraries are self-contained: the default provider is inside libcrypto.lib,
so no separate provider archive is linked. (The OpenSSL 3.3.2 libraries this fork used
before needed one, rt-deps/libproviders.lib, which could not be regenerated from source.
It is no longer used and is no longer in the tree.)

--------------------------------------------------------------------------------
3. bcrypt.dll
--------------------------------------------------------------------------------
Built with _WIN32_WINNT=0x0603, OpenSSL takes its random numbers from BCryptGenRandom
(bcrypt.dll) instead of the older CryptGenRandom. The engine already imported bcrypt.dll
for WinPR, so the set of imported DLLs does not change; Windows RT 8.1 has it (it is part
of every Windows since Vista), and it is neither an api-ms-win-* umbrella DLL nor
secur32.dll, so the import gate in port/rt-configure-pins.txt is unaffected. (Verified
2026-10-21: the same 17 DLLs as the OpenSSL 3.3.2 engine; new symbols BCryptGenRandom,
WSAIoctl, WSASocketA and PathIsURLA, all long-standing Windows APIs.)

--------------------------------------------------------------------------------
4. deps-headers/openssl-3.5.9 -- GENERATED HEADERS, NOT STOCK UPSTREAM
--------------------------------------------------------------------------------
These are the public headers of the OpenSSL 3.5.9 release together with the ones
GENERATED by the configuration run in port/build-openssl-arm32.ps1 (configuration.h
records OPENSSL_NO_ASM and the other options, bn_conf.h the word size, and so on). The
script writes the same set into its -Out directory.

*** Stock upstream OpenSSL 3.5.9 headers are NOT a valid substitute. *** Building
against unconfigured or differently-configured headers while linking these libraries
produces mismatched assumptions -- the failure mode is silent misbehaviour, not a
compile error.

deps-headers/zlib-1.3.2 are the ordinary zlib headers matching z.lib.
